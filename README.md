# AEC 컬러링북 (오늘의 컬러링)

웹 기반 SVG 컬러링북 애플리케이션입니다. 다양한 라인아트를 색칠하고 저장할 수 있습니다.

**라이브 데모**: https://aec-bg.pages.dev

---

## 주요 기능

### 핵심 기능
- **랜덤 이미지**: 페이지 로드 시 Supabase Storage에서 랜덤으로 이미지 선택
- **블록 단위 색칠**: SVG 영역을 클릭하면 선택한 색상으로 채워집니다
- **65+ 색상 팔레트**: 다양한 색상 선택 가능 (10가지 색상 계열)
- **색상 심리 분석**: 사용된 색상을 분석하여 심리 상태 메시지 표시
- **페이지 전환 애니메이션**: 부드러운 fadeSlideIn 효과 (0.3초)
- **뒤로가기/다시하기 (Undo/Redo)**: 색칠 작업 취소 및 복원 (최대 50개 기록)
- **리셋**: 현재 이미지를 초기 상태로 복원
- **포춘 메시지**: 시작 화면에서 랜덤 행운의 메시지 표시

### 저장 옵션
- **기본 이미지 저장**: 색칠한 SVG를 PNG로 저장
- **달력 저장**: 색칠한 그림 + 영문 달력 (1080x2340 해상도)
- **배경화면 저장**: 폰 배경화면용 이미지 (1080x2340 해상도, 가로 크롭)
- **그림일기 저장**: A4 용지 비율 (1080x1527) 원고지 스타일 일기장
  - 날짜 + 요일 + 현재 날씨 표시 (Open-Meteo API 연동)
  - 사용자 텍스트 입력 (최대 98자)
  - 원고지 격자 (14x7칸)

### Supabase Storage 연동
- **SVG 파일 관리**: `images/svg/` 버킷에 색칠용 SVG 파일 저장
- **갤러리 이미지 관리**: `images/gallery/` 버킷에 인트로 화면용 이미지 저장
- 업로드, 목록 조회, 삭제 기능 지원

### 관리자 기능
- **접근 방법**: URL에 `?admin=true` 추가 또는 인트로 화면의 설정(톱니바퀴) 버튼 클릭
- **비밀번호 보호**: 관리자 비밀번호 `a1234`
- **SVG 파일 관리**: 색칠용 SVG 파일 업로드/삭제
- **갤러리 이미지 관리**: 인트로 화면 이미지 업로드/삭제
- **이미지 활성화/비활성화 토글**: 각 이미지별 사용 여부 설정 (localStorage에 저장)

### PC 레이아웃 최적화
- **CSS Grid 레이아웃**: 가로 모드에서 캔버스와 컨트롤 패널 분리 배치
- **뷰포트 피팅**: 스크롤 없이 화면에 맞게 자동 조정
- **반응형 팔레트**: 화면 크기에 따라 팔레트 크기 자동 조절

### 광고 수익화
- **배너 광고**: 결과 페이지 하단에 자동 크기 조절 배너 표시
- **전면 광고**: 저장 버튼 클릭 시, 새로 시작하기 클릭 시 표시
- **광고 빈도 제한**: 세션당 최대 3회, 60초 쿨다운 적용
- **5초 카운트다운**: 전면 광고 표시 후 5초 후 닫기 가능
- **테스트 모드**: 개발 시 플레이스홀더 표시 지원

### 개인정보처리방침
- **PrivacyPage**: 개인정보처리방침 전용 페이지
- **인트로 페이지 접근**: 하단 링크를 통해 접근 가능
- **COPPA 준수**: 어린이 개인정보 보호법 준수 내용 포함
- **광고 정책 안내**: Google AdSense 쿠키 사용 안내

## 4단계 앱 플로우

1. **인트로 화면**: 갤러리 이미지와 포춘 메시지 표시 -> 화면 터치하여 시작 (개인정보처리방침 링크 포함)
2. **색칠 화면**: SVG 컬러링 -> 완료 버튼으로 다음 단계
3. **결과 화면**: 색상 심리 분석 메시지 + 저장 옵션 선택 (이미지/달력/배경화면) + 배너 광고 -> 새로 시작 가능
4. **전면 광고**: 저장 또는 새로 시작 클릭 시 (세션당 최대 3회, 60초 쿨다운)

## 사용 방법

### 로컬 개발

```bash
# 의존성 설치
npm install

# 개발 서버 시작
npm run dev

# 프로덕션 빌드
npm run build

# Cloudflare Pages 배포
npx wrangler pages deploy dist --project-name=aec-bg
```

### 프로덕션 사용

1. https://aec-bg.pages.dev 접속
2. 화면 터치하여 시작
3. 하단 팔레트에서 원하는 색상을 클릭
4. 이미지의 색칠하고 싶은 영역을 클릭
5. 실수했다면 Undo/Redo 버튼으로 되돌릴 수 있습니다
6. 완료 버튼 -> 저장 옵션 선택

### 관리자 페이지 접근

1. URL에 `?admin=true` 파라미터 추가 (예: `https://aec-bg.pages.dev?admin=true`)
2. 또는 인트로 화면 우측 상단의 설정(톱니바퀴) 버튼 클릭
3. 비밀번호 `a1234` 입력
4. SVG 파일 또는 갤러리 이미지 탭 선택하여 관리

## 기술 스택

- **Frontend**: React 18 + TypeScript
- **Build Tool**: Vite 7
- **Styling**: CSS Modules + CSS Grid
- **Backend**: Supabase Storage (이미지 저장소)
- **Weather API**: Open-Meteo (무료, API 키 불필요)
- **광고**: Google AdSense (배너 + 전면 광고)
- **Deployment**: Cloudflare Pages
- **Font**: Pretendard

## Supabase 설정

### Storage 버킷 구조

```
images/
├── svg/           # 색칠용 SVG 파일
│   ├── 1738123456_DavidHockney.svg
│   ├── 1738123457_FridaKahlo.svg
│   └── ...
└── gallery/       # 인트로 갤러리 이미지
    ├── 1738123458_example1.png
    ├── 1738123459_example2.jpg
    └── ...
```

### 이미지 활성화/비활성화

- 비활성화된 이미지 목록은 localStorage의 `aec-disabled-images` 키에 JSON 배열로 저장
- 관리자 페이지에서 토글 스위치로 각 이미지의 사용 여부 설정 가능
- 비활성화된 이미지는 앱에서 자동으로 제외됨

## 저장 기능 상세

### 기본 이미지 저장
- 색칠한 SVG를 PNG로 변환하여 저장
- 파일명: `coloring_[이미지명]_[타임스탬프].png`

### 달력 저장
- 출력 해상도: 1080x2340 픽셀 (폰 최적화)
- 레이아웃: 상단 55% 이미지 + 하단 45% 달력
- 달력 표기: 영문 (January~December, SUN~SAT)
- 파일명: `calendar_[이미지명]_[연월].png`

### 배경화면 저장
- 출력 해상도: 1080x2340 픽셀 (폰 최적화)
- 크롭 방식: 가로 기준 맞춤, 세로 중앙 정렬
- 투명 배경 없이 흰색 배경 적용
- 파일명: `wallpaper_[이미지명]_[타임스탬프].png`

### 그림일기 저장
- 출력 해상도: 1080x1527 픽셀 (A4 비율 1:1.414)
- 레이아웃 구성:
  - 헤더 6%: 날짜 + 요일 + 날씨 아이콘 4개 (현재 날씨만 컬러)
  - 이미지 50%: 색칠한 그림
  - 메시지 44%: 사용자 입력 텍스트 (원고지 스타일 14x7 격자)
- 날씨 API: Open-Meteo (서울 기준, 무료)
- 파일명: `diary_[YYYYMMDD]_[이미지명].png`

## 반응형 레이아웃

### 모바일 (세로 모드)
- 세로 배치: 캔버스 -> 팔레트 -> 컨트롤
- 터치 최적화 버튼 크기

### 태블릿/PC (가로 모드)
- CSS Grid 레이아웃 사용
- 왼쪽: 캔버스 영역 (전체 높이)
- 오른쪽: 팔레트 (상단) + 컨트롤 (하단)
- 스크롤 없이 뷰포트에 맞춤
