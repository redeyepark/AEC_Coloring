# SPEC-UI-003 수용 기준: "내 작품" (MyWorks) 갤러리 기능

---

## 1. 내 작품 갤러리 (REQ-MW)

### AC-MW-001: 작품 갤러리 그리드 표시

**Given** Supabase Storage `myworks/` 폴더에 2개 이상의 작품 이미지가 업로드되어 있을 때
**When** 사용자가 더보기 > 내 작품 메뉴를 터치하여 MyWorksPage에 진입하면
**Then** 모든 작품이 그리드 레이아웃(auto-fill, minmax 150px)으로 표시되고
- 각 카드에 썸네일 이미지, 제목, 작가명이 표시되며
- 최신 업로드 순으로 정렬되어 있어야 한다

### AC-MW-002: 작품 전체화면 보기

**Given** MyWorksPage에 작품 목록이 표시되어 있을 때
**When** 사용자가 특정 작품 카드를 터치하면
**Then** 해당 작품이 전체화면 오버레이로 표시되고
- 반투명 검정 배경(rgba(0,0,0,0.9)) 위에 이미지가 중앙 정렬되며
- 이미지 하단에 제목과 작가명이 표시되고
- 우측 상단에 닫기(X) 버튼이 표시되어야 한다

### AC-MW-003: 전체화면 닫기 동작

**Given** 전체화면 오버레이가 표시되어 있을 때
**When** 사용자가 다음 중 하나의 동작을 수행하면:
  - 우측 상단 X 버튼 터치
  - 이미지 외 배경 영역 터치
  - ESC 키 입력
**Then** 전체화면 오버레이가 닫히고 갤러리 목록이 다시 표시되어야 한다

### AC-MW-004: 빈 갤러리 상태

**Given** Supabase Storage `myworks/` 폴더에 업로드된 작품이 없을 때
**When** 사용자가 MyWorksPage에 진입하면
**Then** "아직 등록된 작품이 없습니다" 메시지가 표시되어야 한다

### AC-MW-005: 일반 사용자 업로드 불가

**Given** 일반 사용자가 MyWorksPage에 접근했을 때
**When** 페이지가 렌더링되면
**Then** 업로드 버튼, 삭제 버튼, 수정 버튼이 화면에 표시되지 않아야 한다

## 2. 관리자 작품 관리 (REQ-ADM)

### AC-ADM-001: 관리자 페이지 3번째 탭 표시

**Given** 관리자가 AdminPage에 비밀번호 인증을 완료하고 진입했을 때
**When** AdminPage가 렌더링되면
**Then** 상단에 3개의 탭 [SVG 파일] [갤러리 이미지] [내 작품]이 표시되고
- "내 작품" 탭을 클릭하면 myworks 폴더의 이미지 목록이 표시되어야 한다

### AC-ADM-002: 작품 업로드 메타데이터 폼

**Given** 관리자가 AdminPage의 "내 작품" 탭을 선택했을 때
**When** 업로드 영역이 표시되면
**Then** 다음 입력 요소가 표시되어야 한다:
  - 파일 선택 버튼 (PNG/JPG만 허용)
  - 제목 입력 필드 (최대 50자)
  - 작가명 입력 필드 (최대 30자)
  - 업로드 버튼 (제목과 작가명 모두 입력 시에만 활성화)

### AC-ADM-003: 작품 업로드 성공

**Given** 관리자가 "내 작품" 탭에서 JPG 파일을 선택하고, 제목 "봄의 꽃밭", 작가명 "김영희"를 입력했을 때
**When** 업로드 버튼을 클릭하면
**Then** Supabase Storage `myworks/` 폴더에 `{timestamp}_봄의-꽃밭_by_김영희.jpg` 형식으로 파일이 업로드되고
- "업로드 완료" 성공 메시지가 표시되며
- 작품 목록이 자동으로 새로고침되어 새 작품이 표시되어야 한다

### AC-ADM-004: 작품 삭제

**Given** 관리자가 "내 작품" 탭에서 작품 목록을 보고 있을 때
**When** 특정 작품의 삭제 버튼을 클릭하면
**Then** "해당 작품을 삭제하시겠습니까?" 확인 다이얼로그가 표시되고
- 확인 시 해당 파일이 Supabase Storage에서 삭제되며
- 목록이 자동으로 새로고침되어야 한다

### AC-ADM-005: 메타데이터 미입력 시 업로드 차단

**Given** 관리자가 "내 작품" 탭에서 파일을 선택했지만 제목 또는 작가명이 비어 있을 때
**When** 업로드 버튼 영역을 확인하면
**Then** 업로드 버튼이 비활성화(disabled) 상태이고 클릭해도 업로드가 실행되지 않아야 한다

## 3. 데이터 계층 (REQ-DATA)

### AC-DATA-001: ImageType 확장

**Given** `src/lib/supabase.ts`의 ImageType이 `'myworks'`를 포함하도록 확장되었을 때
**When** `listImages('myworks')`를 호출하면
**Then** Supabase Storage `images/myworks/` 폴더의 이미지 파일 목록을 반환해야 한다

### AC-DATA-002: 파일명 메타데이터 파싱

**Given** 파일명이 `1707800000000_봄의-꽃밭_by_김영희.jpg` 형식일 때
**When** `parseMyWorkFilename()` 함수에 해당 파일명을 전달하면
**Then** `{ title: "봄의 꽃밭", artist: "김영희" }` 객체를 반환해야 한다
- 타임스탬프 접두사가 제거되고
- 하이픈이 공백으로 복원되어야 한다

## 4. 엣지 케이스

### EC-001: 비정상 파일명 형식

**Given** `myworks/` 폴더에 `_by_` 구분자가 없는 파일(예: `random-image.jpg`)이 존재할 때
**When** MyWorksPage에서 작품 목록을 로드하면
**Then** 해당 파일은 제목을 파일명 전체로, 작가명을 "알 수 없음"으로 표시해야 한다

### EC-002: 특수문자 포함 제목

**Given** 관리자가 제목에 특수문자(예: `봄의 꽃밭!@#$%`)를 입력했을 때
**When** sanitize 처리 후 업로드를 실행하면
**Then** 파일명에서 특수문자가 제거되어 `봄의-꽃밭`으로 저장되고
- 갤러리에서는 "봄의 꽃밭"으로 정상 표시되어야 한다

### EC-003: 매우 긴 제목/작가명

**Given** 관리자가 50자 제한 제목 필드에 최대 길이를 입력했을 때
**When** 갤러리 카드에 표시되면
**Then** 텍스트가 카드 너비를 초과하지 않도록 말줄임(...) 처리되어야 한다

### EC-004: 이미지 로드 실패

**Given** Supabase Storage 연결이 불안정할 때
**When** MyWorksPage에서 이미지 목록 로드가 실패하면
**Then** 에러 메시지가 표시되고, 사용자가 재시도할 수 있는 안내가 제공되어야 한다

### EC-005: 대용량 이미지 업로드

**Given** 관리자가 10MB를 초과하는 이미지 파일을 선택했을 때
**When** 업로드를 시도하면
**Then** "파일 크기가 10MB를 초과합니다" 에러 메시지를 표시하고 업로드를 중단해야 한다

## 5. Quality Gate 기준

### 기능 완성도

- [ ] MyWorksPage placeholder가 실제 갤러리로 교체됨
- [ ] AdminPage에 "내 작품" 탭이 추가됨
- [ ] 관리자 업로드 폼(파일+제목+작가명)이 정상 동작함
- [ ] 전체화면 뷰어가 정상 동작함 (열기/닫기)
- [ ] 파일명 인코딩/디코딩이 정상 동작함
- [ ] 3가지 상태(로딩/에러/빈 목록)가 정상 처리됨

### 코드 품질

- [ ] TypeScript strict mode 통과 (타입 에러 없음)
- [ ] CSS Module 스코핑 적용 (전역 스타일 오염 없음)
- [ ] 기존 기능 회귀 없음 (SVG, Gallery 탭 정상 동작)

### UX 기준

- [ ] 모바일 기준 터치 타겟 최소 44x44px
- [ ] 전체화면 뷰어에서 body 스크롤 잠금
- [ ] 이미지 lazy loading 적용

### 성능 기준

- [ ] 작품 목록 로드 2초 이내
- [ ] 전체화면 이미지 로드 3초 이내
- [ ] 관리자 업로드 완료 5초 이내 (10MB 이하)
