## 2. 상세 인수 기준

### AC-01: Gallery 이미지에서 색칠놀이 SVG 변환 성공

```gherkin
Feature: Gallery 탭 색칠놀이 SVG 변환

  Scenario: 갤러리 이미지를 색칠놀이 SVG로 변환
    Given 관리자가 AdminPage에 인증되어 있다
    And Gallery 탭이 선택되어 있다
    And 갤러리 이미지가 1개 이상 존재한다

    When 관리자가 특정 이미지의 "색칠놀이 변환" 버튼을 클릭한다
    Then 해당 이미지 카드 아래에 인라인 변환 패널이 표시된다
    And k-colors 슬라이더가 기본값 6으로 표시된다
    And 슬라이더 범위가 2~16이다

    When 관리자가 k-colors를 8로 조절한다
    And "변환 시작" 버튼을 클릭한다
    Then 변환이 시작되고 로딩 인디케이터가 표시된다

    When 변환이 완료되면
    Then SVG 미리보기 이미지가 표시된다
    And 메타데이터(크기, 색상 수, 처리 시간)가 표시된다
    And 색상 팔레트(각 색상의 swatch, hex, 비율)가 표시된다
    And "SVG 저장", "다운로드", "닫기" 버튼이 표시된다
```

### AC-02: 변환 중 로딩 상태 및 UI 피드백

```gherkin
  Scenario: 변환 진행 중 로딩 상태 표시
    Given 관리자가 Gallery 탭에서 이미지의 변환 패널을 열었다

    When "변환 시작" 버튼을 클릭한다
    Then "변환 시작" 버튼이 비활성화(disabled)된다
    And 스피너 애니메이션과 "이미지를 분석하고 변환하는 중..." 텍스트가 표시된다
    And 다른 이미지의 관리 기능(토글, 삭제, 노출 설정)은 정상 동작한다

    When 변환이 완료되면
    Then 로딩 인디케이터가 사라진다
    And "변환 시작" 버튼이 다시 활성화된다
```

### AC-03: 변환된 SVG를 Supabase에 저장

```gherkin
  Scenario: 변환된 SVG를 Supabase svg/ 폴더에 저장
    Given 갤러리 이미지 "sunset.jpg"의 변환이 성공적으로 완료되었다
    And 변환 결과 미리보기가 표시되고 있다

    When 관리자가 "SVG 저장" 버튼을 클릭한다
    Then SVG 파일이 Supabase images/svg/ 폴더에 업로드된다
    And 파일명은 "converted_sunset.svg" 형식이다
    And "SVG 파일이 저장되었습니다." 성공 메시지가 표시된다

    When 관리자가 SVG 탭으로 전환하면
    Then 저장된 "converted_sunset.svg" 파일이 목록에 표시된다
```

### AC-04: 변환된 SVG를 로컬 다운로드

```gherkin
  Scenario: 변환된 SVG를 로컬 파일로 다운로드
    Given 갤러리 이미지의 변환이 성공적으로 완료되었다
    And 변환 결과 미리보기가 표시되고 있다

    When 관리자가 "다운로드" 버튼을 클릭한다
    Then 브라우저의 파일 다운로드가 시작된다
    And 다운로드 파일명은 "converted_{원본파일명}.svg" 형식이다
    And 다운로드된 SVG 파일은 색칠놀이용으로 후처리된 상태이다
```

### AC-05: 변환 실패 시 에러 처리

```gherkin
  Scenario: 변환 실패 시 에러 메시지 표시
    Given 관리자가 Gallery 탭에서 이미지의 변환 패널을 열었다

    When "변환 시작" 버튼을 클릭했으나 변환이 실패한다
    Then 에러 메시지 "변환에 실패했습니다: {구체적 에러 내용}"이 빨간색으로 표시된다
    And 로딩 인디케이터가 사라진다
    And "변환 시작" 버튼이 다시 활성화된다
    And 기존 갤러리 이미지는 손상되지 않는다
    And "SVG 저장" 버튼은 표시되지 않는다

  Scenario: 대용량 이미지 변환 시도
    Given 갤러리에 4096px 초과 또는 20MB 초과 이미지가 있다

    When 해당 이미지의 변환을 시도한다
    Then 이미지 크기/용량 초과 에러 메시지가 표시된다
    And 변환이 실행되지 않는다
```

### AC-06: 중복 파일 덮어쓰기 확인

```gherkin
  Scenario: 이미 변환된 SVG가 존재할 때 덮어쓰기 확인
    Given 갤러리 이미지 "sunset.jpg"의 변환이 완료되었다
    And Supabase svg/ 폴더에 "converted_sunset.svg"가 이미 존재한다

    When 관리자가 "SVG 저장" 버튼을 클릭한다
    Then "이미 변환된 파일이 존재합니다. 덮어쓰시겠습니까?" 확인 다이얼로그가 표시된다

    When 관리자가 "확인"을 선택한다
    Then SVG 파일이 덮어쓰기되고 성공 메시지가 표시된다

    When 관리자가 "취소"를 선택한다
    Then 저장이 취소되고 변환 결과 미리보기는 유지된다
```

### AC-07: 변환 패널 토글 및 상태 초기화

```gherkin
  Scenario: 변환 패널 닫기 시 상태 초기화
    Given 갤러리 이미지의 변환이 완료되어 미리보기가 표시되고 있다

    When 관리자가 "닫기" 버튼을 클릭한다
    Then 인라인 변환 패널이 닫힌다
    And 변환 결과와 에러 상태가 초기화된다

  Scenario: 다른 이미지의 변환 버튼 클릭 시 이전 패널 닫힘
    Given 이미지 A의 변환 패널이 열려 있다

    When 이미지 B의 "색칠놀이 변환" 버튼을 클릭한다
    Then 이미지 A의 변환 패널이 닫힌다
    And 이전 변환 결과와 에러가 초기화된다
    And 이미지 B의 변환 패널이 새로 열린다
    And k-colors 슬라이더가 기본값 6으로 초기화된다

  Scenario: 같은 이미지의 변환 버튼 재클릭 시 패널 닫힘
    Given 이미지 A의 변환 패널이 열려 있다

    When 이미지 A의 "색칠놀이 변환" 버튼을 다시 클릭한다
    Then 이미지 A의 변환 패널이 닫힌다
```

### AC-08: 기존 convert 탭 기능 무변경 확인

```gherkin
  Scenario: convert 탭 기존 기능 회귀 테스트
    Given 관리자가 AdminPage에 인증되어 있다

    When "이미지 변환" 탭을 선택한다
    Then 기존 갤러리 이미지 그리드가 표시된다
    And 이미지 선택 후 k-colors 슬라이더로 색상 수 조절이 가능하다
    And "SVG로 변환" 버튼이 정상 동작한다
    And 변환 결과 미리보기가 정상 표시된다
    And "SVG 저장" 및 "다운로드" 기능이 정상 동작한다
    And Gallery 탭의 변환과 독립적으로 동작한다
```

## 3. 품질 게이트 (Quality Gate)

| 항목 | 기준 |
|------|------|

| 인라인 패널 | 변환 버튼 클릭 시 k-colors 슬라이더 + 변환 시작 버튼이 포함된 패널이 표시됨 |

| 에러 처리 | 변환 실패 시 사용자에게 명확한 에러 메시지가 표시됨 |
| 회귀 확인 | 기존 convert 탭 기능이 정상 동작함 |

## 4. 검증 방법

### 수동 테스트 체크리스트

- [ ] Gallery 탭 진입 시 각 이미지에 "색칠놀이 변환" 버튼이 보이는가
- [ ] 버튼 클릭 시 인라인 패널이 열리는가
- [ ] k-colors 슬라이더가 2~16 범위로 동작하는가
- [ ] 변환 시작 후 로딩 인디케이터가 표시되는가
- [ ] 변환 완료 후 SVG 미리보기가 정상 렌더링되는가
- [ ] 메타데이터(크기, 색상 수, 처리 시간)가 정확한가
- [ ] 색상 팔레트가 정상 표시되는가
- [ ] "SVG 저장" 클릭 시 Supabase에 정상 업로드되는가
- [ ] "다운로드" 클릭 시 파일이 로컬에 다운로드되는가
- [ ] "닫기" 클릭 시 패널이 닫히고 상태가 초기화되는가
- [ ] 다른 이미지 변환 버튼 클릭 시 이전 패널이 닫히는가
- [ ] 변환 실패 시 에러 메시지가 표시되는가
- [ ] 변환 중 다른 이미지의 토글/삭제가 정상 동작하는가
- [ ] convert 탭 기능이 기존과 동일하게 동작하는가
- [ ] SVG 탭에서 저장된 변환 파일이 확인되는가

### Definition of Done

1. 모든 필수 인수 기준(AC-01 ~ AC-08) 통과
2. TypeScript 컴파일 에러 0건
3. `npm run build` 정상 완료
4. 브라우저에서 수동 테스트 체크리스트 전항목 확인
5. 기존 convert 탭 기능 회귀 테스트 통과
