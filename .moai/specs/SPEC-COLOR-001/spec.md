## 1. 개요 및 목표

### 1.1 프로젝트 개요

베레모와 안경을 착용한 신사의 라인 드로잉 이미지(AEC_BG.png)를 활용한 웹 기반 컬러링북 애플리케이션을 개발한다. 사용자가 이미지의 각 영역을 클릭하여 선택한 색상으로 채울 수 있는 직관적인 인터페이스를 제공한다.

### 1.2 목표

- 라인아트 이미지를 Canvas에 로드하여 표시
- Flood Fill 알고리즘을 통한 영역 색칠 기능 구현
- 직관적인 색상 팔레트 UI 제공
- 외부 라이브러리 없이 순수 JavaScript로 구현

### 1.3 대상 이미지

- 파일 경로: `_AEC/AEC_BG.png`
- 특징: 베레모, 안경, 셔츠, 넥타이, 재킷을 착용한 신사의 라인 드로잉
- 영역: 배경, 베레모, 머리카락, 얼굴/피부, 안경테, 셔츠, 넥타이, 재킷 등 명확한 경계

## 5. 명세 (Specifications)

### 5.1 Flood Fill 알고리즘 명세

#### 5.1.1 알고리즘 개요

Queue 기반 4방향(상하좌우) Flood Fill 알고리즘을 사용한다.

#### 5.1.2 의사 코드

```
function floodFill(x, y, fillColor):
    targetColor = getPixelColor(x, y)

    if targetColor == fillColor:
        return  // 이미 같은 색상

    if isBlackLine(targetColor):
        return  // 경계선은 채우지 않음

    queue = [(x, y)]
    visited = Set()

    while queue is not empty:
        (cx, cy) = queue.pop()

        if (cx, cy) in visited:
            continue

        if not isValidPixel(cx, cy):
            continue

        currentColor = getPixelColor(cx, cy)

        if currentColor != targetColor:
            continue

        setPixelColor(cx, cy, fillColor)
        visited.add((cx, cy))

        queue.push((cx-1, cy))  // 왼쪽
        queue.push((cx+1, cy))  // 오른쪽
        queue.push((cx, cy-1))  // 위
        queue.push((cx, cy+1))  // 아래
```

#### 5.1.3 경계선 감지

- 검은색 정의: RGB(0,0,0) 또는 밝기 값 < 50
- 허용 오차: RGB 각 채널 +/- 30 범위 내
