## 1. 개요 및 목표

### 1.1 프로젝트 개요

다양한 라인 드로잉 이미지를 활용한 웹 기반 컬러링북 애플리케이션을 개발한다. 사용자가 이미지의 각 영역을 클릭하여 선택한 색상으로 채울 수 있는 직관적인 인터페이스를 제공한다. Supabase Storage를 통한 이미지 관리 시스템과 관리자 기능을 포함한다.

### 1.2 목표

- SVG path 기반의 영역별 색칠 기능 구현
- 직관적인 65+ 색상 팔레트 UI 제공 (10가지 색상 계열)
- Undo/Redo/Reset 기능을 통한 편리한 작업 관리
- 달력 저장, 배경화면 저장, 그림일기 저장 기능 제공
- Supabase Storage를 통한 이미지 관리
- 관리자 페이지를 통한 이미지 업로드/삭제/토글 기능
- PC/모바일 반응형 레이아웃 지원
- Cloudflare Workers를 통한 정적 배포

### 1.3 배포 URL

- 라이브 서비스: https://aec-coloring.redeyepark.workers.dev

## 5. 명세 (Specifications)

### 5.1 Supabase Storage 명세

#### 5.1.1 버킷 구조

```
images/
├── svg/           # 색칠용 SVG 파일
└── gallery/       # 인트로 갤러리 이미지
```

#### 5.1.2 파일 명명 규칙

- 형식: `{timestamp}_{originalName}.{extension}`
- 예시: `1738123456_DavidHockney.svg`

#### 5.1.3 API 함수

- `uploadImage(file, type)`: 이미지 업로드
- `listImages(type)`: 이미지 목록 조회
- `deleteImage(path)`: 이미지 삭제
- `getImageUrl(path)`: 퍼블릭 URL 생성

### 5.2 관리자 페이지 명세

#### 5.2.1 접근 방법

- URL 파라미터: `?admin=true`
- UI 버튼: 인트로 화면 우측 상단 설정(톱니바퀴) 아이콘

#### 5.2.2 인증

- 비밀번호: `a1234`
- 인증 후 세션 유지 (페이지 새로고침 시 재인증 필요)

#### 5.2.3 기능

- SVG 탭: SVG 파일 업로드/삭제/토글
- 갤러리 탭: 갤러리 이미지 업로드/삭제/토글
- 토글 스위치: 이미지 활성화/비활성화

### 5.3 이미지 토글 명세

#### 5.3.1 저장 위치

- localStorage 키: `aec-disabled-images`
- 형식: JSON 배열 (`["svg/image1.svg", "gallery/image2.png"]`)

#### 5.3.2 동작 방식

- 토글 OFF: 이미지 경로를 배열에 추가
- 토글 ON: 이미지 경로를 배열에서 제거
- 앱 로드 시 배열에 포함된 이미지는 필터링하여 제외

### 5.4 PC 레이아웃 명세

### 5.7 저장 기능 명세

#### 5.6.1 기본 이미지 저장

- 출력 형식: PNG
- 파일명: `coloring_[이미지명]_[타임스탬프].png`

#### 5.6.2 달력 저장

- 출력 해상도: 1080x2340 픽셀
- 레이아웃: 상단 55% 이미지 + 하단 45% 달력
- 달력 표기: 영문 (January~December, SUN~SAT)
- 파일명: `calendar_[이미지명]_[연월].png`

#### 5.6.3 배경화면 저장

- 출력 해상도: 1080x2340 픽셀
- 크롭 방식: 가로 기준 맞춤, 세로 중앙 정렬
- 파일명: `wallpaper_[이미지명]_[타임스탬프].png`

#### 5.6.4 그림일기 저장 (신규)

- 출력 비율: A4 용지 비율 (1:1.414)
- 출력 해상도: 1080x1528 픽셀
- 파일명: `diary_[이미지명]_[YYYY-MM-DD].png`

### 5.8 그림일기 레이아웃 명세

#### 5.8.1 전체 구조

```

+----------------------------------+
```

#### 5.8.2 헤더 구성

| 요일 | 월~일요일 (한글) | 18px |
| 날씨 아이콘 | 맑음, 흐림, 비, 눈 | 4개 아이콘, 현재 날씨 강조 |

- API: Open-Meteo (무료, 키 불필요)
- 엔드포인트: `https://api.open-meteo.com/v1/forecast`
- 파라미터: 위치(위도/경도), 현재 날씨 코드
- 날씨 매핑:
  - WMO 코드 0-3: 맑음
  - WMO 코드 45-67: 흐림
  - WMO 코드 71-86: 눈
  - WMO 코드 기타 강수: 비

#### 5.8.4 원고지 스타일 격자

- 격자 크기: 14열 x 7행
- 셀 크기: 동일 비율
- 스타일: 연한 회색 테두리
- 텍스트: 한 글자씩 셀에 배치

#### 5.8.5 현재 날씨 강조

- 현재 날씨에 해당하는 아이콘에 색상 강조 적용
- 비선택 아이콘: 회색조 또는 낮은 불투명도
- 선택 아이콘: 원래 색상 + 테두리 강조
