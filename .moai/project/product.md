## 1. 제품 개요

### 1.1 소개

AEC 컬러링북은 웹 브라우저에서 작동하는 대화형 SVG 색칠 애플리케이션입니다. 사용자가 다양한 라인아트 이미지를 선택하고, 직관적인 색상 팔레트를 사용하여 각 영역을 클릭만으로 색칠할 수 있습니다.

### 1.2 핵심 가치

- **단순함**: 별도의 설치 없이 브라우저만으로 즉시 사용 가능
- **직관성**: 클릭 한 번으로 영역 색칠, 누구나 쉽게 사용
- **접근성**: 모바일과 데스크톱 모두 지원하는 반응형 디자인
- **다양한 저장 옵션**: 달력 이미지 또는 배경화면으로 저장 가능

### 1.3 제품 비전

디지털 색칠 공부를 통해 창의성과 집중력을 키우고, 스트레스 해소와 명상적 활동을 제공하는 것을 목표로 합니다. 어린이부터 성인까지 누구나 즐길 수 있는 간단하면서도 만족스러운 색칠 경험을 제공합니다.

## 2. 대상 사용자

### 2.1 주요 사용자 그룹

#### 어린이 (5-12세)

- **요구사항**: 간단한 인터페이스, 다양한 색상, 실수 수정 가능
- **사용 시나리오**: 가정에서 부모와 함께, 또는 교육 환경에서 활용

#### 성인 힐링족 (20-50세)
- **특성**: 스트레스 해소, 명상적 활동 선호
- **요구사항**: 깔끔한 UI, 완성작 저장, 빠른 응답 속도
- **사용 시나리오**: 점심시간, 퇴근 후 휴식 시간에 간단히 즐기기

#### 미술 교육 목적 사용자
- **특성**: 색상 조합 학습, 기초 미술 교육
- **요구사항**: 다양한 이미지, 색상 이론 학습에 적합한 팔레트
- **사용 시나리오**: 온라인 미술 수업, 자기 주도 학습

- 완성된 그림을 저장해서 자랑하고 싶음

- 업무 스트레스 해소를 위한 간단한 활동 추구

- 완성작을 SNS에 공유하고 싶음

## 3. 핵심 기능

### 3.1 기능 목록

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 인트로 페이지 | 갤러리 이미지 랜덤 표시, 포춘쿠키 메시지, 터치하여 시작 | 필수 |
| 포춘쿠키 메시지 | 50개의 응원/위로 메시지 중 랜덤 표시 (5개 카테고리) | 필수 |
| SVG 이미지 로드 | images.json 매니페스트 기반 동적 이미지 목록 (5개 이미지) | 필수 |
| 64색 팔레트 | 빨강, 주황, 노랑, 초록, 시안, 파랑, 보라, 핑크, 갈색, 피부색, 머터리얼, 무채색 계열 | 필수 |
| 클릭 색칠 | path 영역 클릭 시 선택 색상으로 채우기 | 필수 |
| 뒤로가기 (Undo) | 최대 50개 작업 취소 가능 | 필수 |
| 다시하기 (Redo) | 취소한 작업 복원 가능 | 필수 |
| 초기화 (Reset) | 원본 상태로 복원 | 필수 |
| 결과 페이지 | 완성된 SVG 미리보기, 3가지 저장 옵션, 새로 시작하기 | 필수 |
| 이미지 저장 | 색칠한 그림 원본 그대로 PNG 저장 | 필수 |
| 달력 저장 | 상단 55% 이미지 + 하단 45% 영문 달력 (1080x2340) | 필수 |
| 배경화면 저장 | 가로 기준 크롭으로 배경화면 생성 (1080x2340) | 필수 |
| 저장 상태 표시 | 저장 완료 시 버튼 비활성화 및 토스트 메시지 | 필수 |
| 반응형 레이아웃 | CSS clamp() 기반 동적 크기, 40% 패널 레이아웃 | 필수 |
| 고해상도 지원 | 아이폰 등 고해상도 디바이스 최적화 | 필수 |


#### 3.2.2 뒤로가기 기능

- React useState 훅을 통한 히스토리 관리
- 최대 50개 작업 기억
- 각 작업: 색칠된 요소 ID + 이전 색상 저장
- 히스토리 소진 시 버튼 비활성화

#### 3.2.3 저장 기능

**달력 저장 (Calendar Save)**
- 출력 해상도: 1080x2340 픽셀
- 상단 55%: 색칠된 이미지 영역
- 하단 45%: 영문 달력 표시
- 달력 표기: 영문 (January~December, SUN~SAT)
- 달력 간격: padding 60px, headerHeight 150px

**배경화면 저장 (Wallpaper Save)**
- 출력 해상도: 1080x2340 픽셀
- 가로 기준 크롭: 이미지를 가로 기준으로 맞춤
- 세로 영역: 중앙 정렬 후 상하 크롭

**저장 프로세스**
1. SVG를 XMLSerializer로 문자열 변환
2. Blob으로 변환 후 ObjectURL 생성
3. Image 객체로 로드
4. Canvas에 그리기 (배경 흰색)
5. PNG DataURL로 변환
6. 자동 다운로드 트리거

## 4. 사용 시나리오

### 4.1 기본 사용 흐름 (3단계 플로우)

```
사용자 여정:

[1단계: 인트로]
1. 웹사이트 접속
2. 갤러리 이미지와 포춘쿠키 메시지 확인
3. "화면을 터치하여 시작" 안내 확인
4. 화면 터치/클릭으로 색칠 화면 전환

[2단계: 색칠]
5. 랜덤 이미지 자동 로드
6. 색상 팔레트에서 색상 선택
7. 이미지 영역 클릭하여 색칠
8. 필요시 뒤로가기/다시하기로 수정
9. 완료 버튼 클릭

[3단계: 결과]
10. 완성된 작품 미리보기
11. 원하는 저장 옵션 선택 (이미지/달력/배경화면)
12. 저장 완료 토스트 메시지 확인
13. 새로 시작하기로 처음부터 다시 시작 가능
```

### 4.2 시나리오별 상세

#### 시나리오 A: 첫 방문 사용자
1. 브라우저에서 URL 접속
2. 인트로 화면에서 갤러리 예시 이미지 확인
3. 오늘의 포춘쿠키 메시지 읽기
4. 화면 터치하여 색칠 화면으로 전환
5. 랜덤으로 선택된 이미지와 색상 팔레트 확인
6. 색칠하고 싶은 영역 클릭하여 색칠 시작

#### 시나리오 B: 실수 수정
1. 의도치 않은 영역에 색칠됨
2. "뒤로가기" 버튼 클릭
3. 이전 상태로 복원 확인
4. 올바른 영역에 다시 색칠

#### 시나리오 C: 작품 완성 및 저장 (결과 페이지)
1. 색칠 완료 후 "완료" 버튼 클릭
2. 결과 페이지에서 완성된 작품 미리보기
3. 3가지 저장 옵션 중 선택:
   - "이미지 저장": 색칠한 그림 원본 PNG 저장
   - "달력으로 저장": 상단 이미지 + 하단 달력 (1080x2340)
   - "배경화면으로 저장": 폰 화면 비율로 크롭 (1080x2340)
4. 저장 완료 시 토스트 메시지 표시 ("갤러리에 저장해주세요!")
5. 저장된 버튼은 비활성화되고 "저장됨" 표시

#### 시나리오 D: 새로 시작하기
1. 결과 페이지에서 "새로 시작하기" 버튼 클릭
2. 모든 상태 초기화 (색칠 내역, 현재 이미지)
3. 인트로 페이지로 돌아감
4. 새로운 포춘쿠키 메시지와 함께 다시 시작

#### 시나리오 E: 색칠 중 리셋
1. 색칠 화면에서 현재 작업 결과 불만족
2. "리셋" 버튼 클릭
3. 현재 이미지의 색칠만 초기화 (원본 상태 복원)
4. 동일 이미지로 새로운 색상 조합 시도
