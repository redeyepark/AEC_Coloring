## 1. 제품 개요

### 1.1 소개

오늘의 컬러링은 React 기반의 대화형 SVG 색칠 애플리케이션입니다. Supabase Storage를 통해 이미지를 관리하며, 사용자가 직관적인 색상 팔레트를 사용하여 각 영역을 클릭만으로 색칠할 수 있습니다. 관리자 페이지를 통해 이미지 업로드 및 활성화/비활성화 관리가 가능합니다.

### 1.2 핵심 가치

- **클라우드 기반**: Supabase Storage로 이미지 중앙 관리
- **관리 기능**: 비밀번호 보호 관리자 페이지로 이미지 관리
- **다양한 색상**: 65색 이상의 풍부한 팔레트 (10개 색상 계열)
- **반응형 디자인**: 모바일/데스크톱/PC 가로 모드 완벽 지원
- **다양한 저장 옵션**: 이미지, 달력, 배경화면, 그림일기로 저장 가능
- **광고 수익화**: Google AdSense 통합 (배너/전면 광고, 빈도 제한)
- **링크 공유 미리보기**: Open Graph 메타 태그로 카카오톡/SNS 링크 공유 시 이미지 미리보기 지원

### 1.3 제품 비전

디지털 색칠 공부를 통해 창의성과 집중력을 키우고, 스트레스 해소와 명상적 활동을 제공합니다. 관리자가 이미지를 쉽게 추가/관리할 수 있어 지속적인 콘텐츠 확장이 가능합니다.

### 3.2 기능 상세

#### 3.2.1 색상 팔레트 (65+ 색상)

```
색상 목록 (65+ 색상):

빨강 계열 (5색): #FFEBEE ~ #EF5350
주황 계열 (5색): #FFF3E0 ~ #FFA726
노랑 계열 (6색): #FFFDE7 ~ #FDD835
초록 계열 (5색): #E8F5E9 ~ #66BB6A
시안/청록 계열 (4색): #E0F7FA ~ #00ACC1
파랑 계열 (5색): #E3F2FD ~ #42A5F5
보라 계열 (5색): #F3E5F5 ~ #AB47BC
핑크 계열 (5색): #FCE4EC ~ #EC407A
갈색 계열 (7색): #EFEBE9 ~ #5D4037
피부색 계열 (4색): #F5D5C8 ~ #C9A080
머터리얼 계열 (8색): 강렬한 색상
무채색 계열 (6색): 흰색(지우개) ~ 검정
```

#### 3.2.2 관리자 페이지

- 비밀번호 보호 (a1234)
- URL 파라미터 접근 (?admin=true) 또는 인트로 설정 버튼
- SVG 파일 탭: 색칠용 SVG 이미지 관리
- 갤러리 이미지 탭: 인트로 화면 이미지 관리
- 이미지별 활성화/비활성화 토글 (localStorage 저장)
- 이미지 업로드/삭제/미리보기

#### 3.2.3 색상 심리 분석

결과 페이지에서 사용자가 색칠에 사용한 색상을 분석하여 심리 상태 메시지를 표시합니다.

- **색상 온도 분석**: 따뜻한 색(빨강, 주황, 노랑) / 차가운 색(초록, 파랑, 보라) / 무채색 비율 분석
- **밝기 분석**: 밝은 톤 / 어두운 톤 / 중간 톤 분류
- **다양성 분석**: 사용된 색상 수에 따른 단조로움/다양성 평가
- **심리 메시지**: 15개 이상의 한국어 심리 해석 메시지 랜덤 표시

#### 3.2.4 저장 기능

**이미지 저장 (Image Save)**
- SVG를 PNG로 변환하여 저장
- 원본 해상도 유지

**달력 저장 (Calendar Save)**
- 디바이스 해상도 기반 출력
- 상단 55%: 색칠된 이미지 영역
- 하단 45%: 영문 월간 달력
- 일요일 빨강, 토요일 파랑 색상 적용

**배경화면 저장 (Wallpaper Save)**
- 디바이스 해상도 기반 출력
- 가로 기준 크롭으로 화면에 맞춤

**그림일기 저장 (Diary Save)** - NEW
- A4 용지 비율 (1080 x 1527px)
- 원고지 스타일 레이아웃 (14x7 격자)
- 상단 6%: 날짜 + 날씨 헤더
- 중앙 50%: 색칠 이미지
- 하단 44%: 사용자 텍스트 영역 (최대 98자)
- Open-Meteo API 연동으로 현재 서울 날씨 자동 표시
- 현재 날씨만 컬러, 나머지 날씨는 회색(30% 투명도)

#### 3.2.5 광고 수익화 (전략 B)

**배너 광고 (Banner Ad)**
- 결과 페이지 하단에 자동 크기 조절 배너 표시
- 모바일: 320x100, 데스크톱: 728x90 (반응형)
- Google AdSense 자동 포맷 적용

**전면 광고 (Interstitial Ad)**
- 저장 버튼 클릭 시 표시
- 새로 시작하기 버튼 클릭 시 표시
- 5초 카운트다운 후 닫기 버튼 활성화

**광고 빈도 제한**
- 세션당 최대 3회 전면 광고
- 광고 간 최소 60초 쿨다운
- sessionStorage 기반 세션 추적

**테스트 모드**
- `adConfig.ts`에서 testMode 설정 가능
- 테스트 모드에서는 플레이스홀더 표시
- 어린이 대상 앱으로 추적 스크립트 최소화

#### 3.2.6 개인정보처리방침

**PrivacyPage 컴포넌트**
- 인트로 페이지 하단 링크로 접근
- 뒤로 가기 버튼으로 복귀
- 스크롤 가능한 긴 문서 형식

**주요 내용**
- 수집 정보: 직접 수집 없음, AdSense 자동 수집 안내
- 광고 및 쿠키: Google 광고 설정 링크 제공
- COPPA 준수: 어린이 맞춤 광고 비활성화
- 데이터 저장: localStorage만 사용

#### 3.2.7 링크 공유 미리보기 (Open Graph)

- Open Graph 메타 태그로 링크 공유 시 미리보기 이미지/제목/설명 표시
- 카카오톡, 페이스북, 트위터/X, 라인 등 주요 SNS 플랫폼 지원
- Twitter Card (summary_large_image) 태그로 대형 이미지 미리보기
- gallery/og-image.jpg 파일을 OG 이미지로 사용
- SEO 기본 태그 (description, canonical) 포함

## 4. 앱 흐름

### 4.1 페이지 구성

```
앱 페이지 흐름:

1. 인트로 페이지 (IntroPage)
   - 갤러리 이미지 랜덤 표시
   - 포춘 메시지 표시
   - 화면 터치로 색칠 시작
   - 설정 버튼으로 관리자 접근
   - 개인정보처리방침 링크 (하단)

2. 색칠 페이지 (ColoringPage)
   - 랜덤 SVG 이미지 로드
   - 색상 팔레트로 색칠
   - Undo/Redo/Reset 컨트롤
   - 완성 버튼으로 결과 페이지 이동

3. 결과 페이지 (ResultPage)
   - 완성 작품 미리보기
   - 이미지/달력/배경화면/그림일기 저장 옵션
   - 그림일기: 텍스트 입력 모달 제공
   - 새로 시작 버튼
   - 배너 광고 (하단)
   - 저장/새로시작 시 전면 광고 표시

4. 관리자 페이지 (AdminPage) - 오버레이
   - 비밀번호 인증
   - SVG/갤러리 이미지 관리
   - 활성화/비활성화 토글

5. 개인정보처리방침 페이지 (PrivacyPage) - 오버레이
   - COPPA 준수 정책 안내
   - Google AdSense 쿠키 안내
   - 뒤로 가기 버튼으로 복귀
```

3. SVG 파일 또는 갤러리 이미지 업로드
4. 필요시 이미지 활성화/비활성화 토글
