## 1. 제품 개요

### 1.1 소개

AEC 컬러링북은 웹 브라우저에서 작동하는 대화형 SVG 색칠 애플리케이션입니다. 사용자가 다양한 라인아트 이미지를 선택하고, 직관적인 색상 팔레트를 사용하여 각 영역을 클릭만으로 색칠할 수 있습니다.

### 1.2 핵심 가치

- **단순함**: 별도의 설치 없이 브라우저만으로 즉시 사용 가능
- **직관성**: 클릭 한 번으로 영역 색칠, 누구나 쉽게 사용
- **접근성**: 모바일과 데스크톱 모두 지원하는 반응형 디자인
- **저장 가능**: 완성된 작품을 PNG 이미지로 다운로드

### 1.3 제품 비전

디지털 색칠 공부를 통해 창의성과 집중력을 키우고, 스트레스 해소와 명상적 활동을 제공하는 것을 목표로 합니다. 어린이부터 성인까지 누구나 즐길 수 있는 간단하면서도 만족스러운 색칠 경험을 제공합니다.

## 2. 대상 사용자

### 2.1 주요 사용자 그룹

#### 어린이 (5-12세)
- **특성**: 디지털 기기 친숙, 색칠 공부에 흥미
- **요구사항**: 간단한 인터페이스, 다양한 색상, 실수 수정 가능
- **사용 시나리오**: 가정에서 부모와 함께, 또는 교육 환경에서 활용

#### 성인 힐링족 (20-50세)
- **특성**: 스트레스 해소, 명상적 활동 선호
- **요구사항**: 깔끔한 UI, 완성작 저장, 빠른 응답 속도
- **사용 시나리오**: 점심시간, 퇴근 후 휴식 시간에 간단히 즐기기

#### 미술 교육 목적 사용자
- **특성**: 색상 조합 학습, 기초 미술 교육
- **요구사항**: 다양한 이미지, 색상 이론 학습에 적합한 팔레트
- **사용 시나리오**: 온라인 미술 수업, 자기 주도 학습

### 2.2 사용자 페르소나

#### 페르소나 1: 민준 (8세, 초등학생)
> "엄마, 나 색칠하고 싶어요!"

- 태블릿으로 색칠 공부를 즐기는 어린이
- 실수해도 다시 할 수 있으면 좋겠음
- 완성된 그림을 저장해서 자랑하고 싶음

#### 페르소나 2: 지영 (35세, 직장인)
> "점심시간에 머리 좀 비우고 싶어요"

- 업무 스트레스 해소를 위한 간단한 활동 추구
- 복잡한 앱은 싫고, 바로 시작할 수 있는 것 선호
- 완성작을 SNS에 공유하고 싶음

## 3. 핵심 기능

### 3.1 기능 목록

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| SVG 이미지 로드 | 3개의 라인아트 이미지 중 랜덤 선택 | 필수 |
| 14색 팔레트 | 무지개색 + 피부톤 + 기본색 제공 | 필수 |
| 클릭 색칠 | path 영역 클릭 시 선택 색상으로 채우기 | 필수 |
| 뒤로가기 (Undo) | 최대 50개 작업 취소 가능 | 필수 |
| 초기화 (Reset) | 원본 상태로 복원 | 필수 |
| PNG 저장 | Canvas API로 이미지 변환 후 다운로드 | 필수 |
| 폴라로이드 프레임 | 사진 액자 스타일의 시각적 디자인 | 선택 |
| 반응형 레이아웃 | 모바일/데스크톱 화면 지원 | 필수 |

### 3.2 기능 상세

#### 3.2.1 색상 팔레트

```
색상 목록 (14색):
- 빨강 (#FF0000)     - 주황 (#FFA500)
- 노랑 (#FFFF00)     - 초록 (#008000)
- 파랑 (#0000FF)     - 남색 (#000080)
- 보라 (#800080)     - 분홍 (#FFC0CB)
- 갈색 (#8B4513)     - 베이지 (#F5DEB3)
- 하늘색 (#87CEEB)   - 회색 (#808080)
- 지우개/흰색 (#FFFFFF) - 검정 (#000000)
```

#### 3.2.2 뒤로가기 기능

- 히스토리 스택 방식으로 작업 저장
- 최대 50개 작업 기억
- 각 작업: 색칠된 요소 + 이전 색상 저장
- 히스토리 소진 시 버튼 비활성화

#### 3.2.3 저장 기능

1. SVG를 XMLSerializer로 문자열 변환
2. Blob으로 변환 후 ObjectURL 생성
3. Image 객체로 로드
4. Canvas에 그리기 (배경 흰색)
5. PNG DataURL로 변환
6. 자동 다운로드 트리거

## 4. 사용 시나리오

### 4.1 기본 사용 흐름

```
사용자 여정:
1. 웹사이트 접속
2. 랜덤 이미지 자동 로드
3. 색상 팔레트에서 색상 선택
4. 이미지 영역 클릭하여 색칠
5. 필요시 뒤로가기로 수정
6. 완성 후 저장 버튼 클릭
7. PNG 이미지 다운로드
```

### 4.2 시나리오별 상세

#### 시나리오 A: 첫 방문 사용자
1. 브라우저에서 URL 접속
2. 로딩 메시지 확인 후 이미지 표시
3. 기본 선택 색상(빨강) 확인
4. 색칠하고 싶은 영역 클릭
5. "색칠 완료!" 상태 메시지 확인
6. 다른 색상 선택하여 계속 색칠

#### 시나리오 B: 실수 수정
1. 의도치 않은 영역에 색칠됨
2. "뒤로가기" 버튼 클릭
3. 이전 상태로 복원 확인
4. 올바른 영역에 다시 색칠

#### 시나리오 C: 작품 완성 및 저장
1. 모든 영역 색칠 완료
2. "저장하기" 버튼 클릭
3. PNG 파일 자동 다운로드
4. 파일명: coloring_[이미지명]_[타임스탬프].png

#### 시나리오 D: 처음부터 다시 시작
1. 현재 작업 결과 불만족
2. "처음으로" 버튼 클릭
3. 원본 상태로 초기화
4. 새로운 색상 조합으로 시작
